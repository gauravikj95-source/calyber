# Calyber

Fair pricing for Mumbai ride-hailing. A Design Thinking project that uses machine learning to detect unfair pricing and design a fairer alternative.

## Features

- Fare Forecast
- Fairness Score
- Wait Time Forecast
- Cancellation Risk
- Surge Timing
- Anomaly Detection
- Vehicle Recommender
- Route Comparison
- What-If Explorer
- Policy Simulator
- Fairness Analysis
- Data Explorer

## Data

54,132 Mumbai trips analyzed. Built with Streamlit, Plotly, and scikit-learn.

## Run Locally

pip install -r requirements.txt
streamlit run app.py
